# HTML - Estructura básica de un documento

- **Área:** HTML
- **Tema:** Estructura básica de un documento HTML
- **Issue:** 1
- **Rama:** `html/01-document-structure`

## ¿Qué vi en esta sesión?

- Estructura básica de un documento HTML5.
- Función de `<!DOCTYPE html>`, `<html>`, `<head>` y `<body>`.
- Metadatos con `<meta>` y título del documento con `<title>`.
- Encabezados con `<h1>` y `<h2>`, y párrafos con `<p>`.
- Diferencias entre el título de la pestaña y el encabezado principal.

## ¿Qué aprendí?

- Aprendí que HTML es un lenguaje de marcado que permite definir la estructura y el contenido de una página web.
- Comprendí que `<!DOCTYPE html>` indica que el documento utiliza HTML moderno y que `<html>` es el elemento raíz que contiene a `<head>` y `<body>`.
- Aprendí que `<head>` contiene metadatos e información del documento, mientras que `<body>` contiene el contenido de la página.
- Entendí que `<meta charset="UTF-8">` establece la codificación de caracteres y que `<meta name="viewport">` ayuda a adaptar la página a diferentes dispositivos.
- Aprendí que `<title>` define el título del documento que normalmente aparece en la pestaña del navegador, mientras que `<h1>` representa el encabezado principal visible.
- Comprendí que `<h2>` permite organizar las secciones de la página y que `<p>` se utiliza para crear párrafos.
- Practiqué la creación de una página HTML desde cero, utilizando encabezados, párrafos y metadatos.
- Aprendí que los navegadores pueden corregir ciertos errores de estructura automáticamente, pero que es importante escribir HTML correctamente para mantener un documento claro y bien organizado.

## ¿Qué hice?

Creé una página HTML de presentación personal con encabezados, párrafos y metadatos.
